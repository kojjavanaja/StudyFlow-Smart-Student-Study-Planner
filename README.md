# StudyFlow — Smart Student Study Planner

A responsive portfolio demo built with HTML, CSS, and vanilla JavaScript.

## Features
- Registration and login screens with validation
- Dashboard statistics and completion progress
- Create, edit, complete, search, filter, and delete tasks
- Task subjects, deadlines, priorities, and status
- Subject creation, editing, and deletion
- Study session scheduling and completion tracking
- 25-minute focus timer
- Progress charts based on saved demo data
- Profile editing and data reset
- Responsive desktop and mobile layout

## Run
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. Create a demo account and start adding subjects, tasks, and sessions.

No installation is required.

## Important security note
This is a frontend portfolio prototype. It stores demo account passwords and application data in browser `localStorage`, so it is **not secure production authentication**. Do not use a real or reused password. Password reset is not connected to email. For production, use a secure authentication provider/backend and a persistent database with server-side authorization and password hashing.
